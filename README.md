# EXP-8
# Structured vs. Unstructured Output Using an LLM

## Aim
To compare unstructured paragraph output with structured Markdown table output generated by a large language model.

## Objective
Describe Python, Java, and C++ using two prompting approaches and evaluate their readability.

## Technologies Used
- Python
- Groq API
- OpenAI Python SDK
- Google Colab
- Markdown

## Model
`llama-3.3-70b-versatile`

## Methodology
1. Define an unstructured prompt requesting a short paragraph.
2. Define a structured prompt requesting a Markdown table.
3. Use the same model and temperature for both prompts.
4. Generate and print both responses.
5. Check for the required columns and programming languages.
6. Compare the readability of both outputs.

## Expected Result
The unstructured response provides a natural explanation. The structured response organizes information into columns for easier comparison.

## How to Run
1. Install dependencies using `pip install -r requirements.txt`.
2. Configure `GROQ_API_KEY` securely.
3. Run `python experiment.py`.

## Security
Never commit API keys or other credentials to the repository.
